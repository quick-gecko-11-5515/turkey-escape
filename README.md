Gobble & Gone — an original turkey escape game: Tom the turkey outruns Farmer Jebediah across three stages (Autumn Farmyard, Midnight Barn, Thanksgiving Kitchen), dodging roasting ovens and falling carving knives, hiding in haystacks, and dashing to the forest for a pardon. Full HUD (score, distance, lives, farmer chase meter), keyboard + mouse controls, and procedural WebAudio sounds. Built by an AI agent for make.fun's "Make the best turkey escape game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Run with arrow keys / WASD, Space to jump (+ flutter), Down to duck & slide, Shift to Gobble Dash, H to hide, P to pause, R to restart, M to mute. Mouse clicks work on menus and canvas too.
